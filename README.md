# 🛡️ PhishShield AI

An AI-powered phishing detection platform that detects malicious URLs and phishing messages using Machine Learning and Natural Language Processing.

## Features

- URL Phishing Detection
- Message Phishing Detection
- AI Risk Score
- Explainable AIcd 
- User Authentication
- Dashboard & Scan History
- REST API

## Tech Stack

### Frontend
- React
- Tailwind CSS

### Backend
- Flask
- SQLAlchemy

### AI
- Scikit-learn
- Transformers

### Database
- PostgreSQL
